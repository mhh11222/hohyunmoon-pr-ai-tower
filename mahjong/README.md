# 대만마작 학습용 게임 (STEP A~D)

**이 세트가 절대 기준이다.** 일반 대만마작 교재(144장·꽃 8장)와 숫자가 다르다.
인터넷 규칙과 충돌하면 여기 적힌 것이 이긴다.

## 지금까지 된 것

- **STEP A** — 렌더링 없는 순수 규칙 엔진 + 유닛 테스트.
- **STEP B** — 2인 2D 플레이 가능 버전. 모바일 세로, 봇 1명,
  뽑기·버리기·펑·치·완성 버튼, 산가지 표시, 판마다 점수 계산, 4판 정산까지.
- **STEP C** — **학습 모드 / 실전 모드** 두 갈래.
- **STEP D** — **3D 테이블**(three.js)과 **소리**. 섞기 → 산 쌓기 → 주사위 →
  배패 → 뽑기·버리기 → 펑·치 → 완성 → 산가지 이동까지 모션으로 보여 준다.

```bash
npm test                      # 전체 테스트 (마작 178개)
npm run dev                   # http://localhost:8080/mahjong/ 에서 플레이
node mahjong/demo.js 4        # 콘솔로 4인 한 판 — 섞기부터 정산까지
node mahjong/demo.js 2 7 3    # 2인 / 시드 7 / 3판
```

빌드 없이 정적 파일로 돈다. `mahjong/index.html`을 그대로 열어도 되지만
ES 모듈이라 `file://`보다 로컬 서버가 안전하다.

## 내 세트 스펙이 코드에서 어디에 박혀 있나

| 스펙 | 코드 |
|---|---|
| 총 140장, 꽃은 사계절 4장뿐 | `tiles.js: copiesOf()` — 꽃만 1장 |
| 3인은 만자 제외, 2인은 만자+꽃 제외 | `deck.js: excludedSuits()` |
| 만자 5는 '伍', 백은 백지패 | `tiles.js: tileName()` |
| 자리 꽃 동春 남夏 서秋 북冬 | `tiles.js: SEAT_FLOWER` |
| 손패 16 / 딜러 17 / 완성 17 | `wall.js: dealHands()`, `hand.js: SETS_TO_WIN` |
| 치는 왼쪽 사람 것만 | `calls.js: canChow()` |
| 우선순위 완성 > 펑·깡 > 치 | `calls.js: resolveCalls()` |
| 공개 묶음 잠금, 버린 패 회수 불가 | `game.js: discardable()`, `resolveDiscard()` |
| 점수 = 기본 10 + 보너스×10 | `score.js: handValue()` |
| 안 부르고 + 직접 뽑아 = 3 | `score.js: countBonuses()` |
| 2인 직접 뽑기 2배 | `score.js: payments()` |
| 산가지 10(빨강1)·50(검정8)·100(빨강5) | `sticks.js: DENOMS` |
| 시작액 4인 500 / 3인 700 / 2인 1000 | `sticks.js: STARTING` |

산가지는 52개·2,170점이고 인원별 배분이 딱 떨어진다 (4인 500×4+170, 3인 700×3+70,
2인 1000×2+170). 거스름돈 더미는 값을 잃지도 얻지도 않으므로 **손익 합계는 언제나 0**이다.

## 첫 화면 — 기본 룰 카드

게임을 처음 열면 룰 카드 6장이 뜬다. 실제 패 그림으로 보여 주고,
`다음`·`이전`으로 넘기거나 좌우로 밀면 되고, 언제든 `건너뛰기`로 빠져나온다.
나중에 다시 보려면 툴바 `?` → `기본 룰 다시 보기`.

1. 이렇게 만들면 이깁니다 — 묶음 5 + 짝 1 = 17장
2. 묶음은 두 종류뿐 — 계단 / 세쌍둥이
3. 이 세트의 패 — 140장, 꽃은 사계절 4장뿐
4. 한 턴은 두 박자 — 뽑고 → 버리고, 차례는 반시계
5. 남이 버린 패 가져오기 — 펑 / 치 / 완성, 우선순위
6. 점수와 산가지 — (보너스+1)×10, 누가 내나

## 두 가지 모드

시작 화면에서 고르고, 게임 중에도 위쪽 배지를 눌러 언제든 바꿀 수 있다.

| | 🎓 학습 모드 | ⚡ 실전 모드 |
|---|---|---|
| 자막 | 단계마다 왜 그런지 설명 + 연상 고리 | 누가 무엇을 버렸는지만 |
| 손패 코치 | 몇 묶음 섰는지 · 짝 후보 · 무엇을 버리는 게 정석인지 | 없음 |
| 텐파이 | "이 패가 오면 완성" 대기패를 패 그림으로 | 없음 |
| 패를 누르면 | 그 패의 연상 고리 ("1삭 — 돈은 한 푼 남으면 새처럼 날아간다") | 없음 |
| 한 수 물리기 | 있음 (최근 20수) | 없음 |
| 봇 속도 | 느리게 (0.9초) | 빠르게 (0.42초) |

`⏸ 멈춤`과 `?`(연상 고리 19개 모음)은 두 모드 모두에서 쓸 수 있다.

## 조작

- 내 차례에 **뽑기** → 손패에서 버릴 패를 눌러 고르고 **버리기** (같은 패를 두 번 누르면 바로 버림).
- 상대가 버린 패를 부를 수 있으면 **펑 / 치 / 완성 / 패스** 버튼이 뜬다. 부르기는 선택이다.
- 완성하면 묶음별로 무엇이 계단이고 세쌍둥이인지 이름표를 붙여 보여주고, 보너스와
  산가지 이동을 표로 정리한다.

## 상대는 우리 집 고양이

| | 이름 | 몸집 | 울음소리 | 등장 |
|---|---|---|---|---|
| 🐈 | **포도** | 제일 작다 | 제일 높다 | 2인부터 항상 |
| 🐈 | **감자** | 중간 | 중간 | 3인부터 |
| 🐈 | **막내** | 제일 크고 뚱뚱하다 | 제일 낮고 우렁차다 | 4인 |

- 2인: 포도 / 3인: 감자·포도 / 4인: 세 마리 다 (`ui/cats.js: opponentsFor`)
- 상대 패널에 실제 사진 아바타가 뜨고, 상황마다 **말풍선 이모지**로 감정을 표현한다:
  판 시작 인사(😺), 펑·치(😼 "펑!"), 완성(😻), 산가지 내줄 때(😿),
  내가 버림패를 가져가면 발끈(😾 "야옹!!"), 유국(😹).
- 우는 상황이면 **합성 야옹 소리**가 같이 난다 — 몸집대로 포도가 제일 높고
  막내가 제일 낮고 길다. (사진과 마찬가지로 소리 파일은 없다. 전부 WebAudio.)

## 손 모션 — 실제 게임처럼

패가 저절로 날아가지 않는다. **내 쪽은 사람 손, 상대 쪽은 고양이 앞발**이
나와서 산에서 패를 집고, 강에 내려놓고, 주사위를 던진다.
(빈손이 다가감 → 집어서 나름 → 내려놓고 물러남 3단계, `table3d.js: handCarry`.)

## 소리 — 파일 없이 만든다

저작권 있는 곡을 쓰지 않는다. 전부 WebAudio로 그 자리에서 합성한다.

- **효과음**: 패가 부딪히는 딱 소리(순간음 + 나무 울림), 섞기, 주사위, 산가지,
  완성 팡파르, 고양이 야옹(포먼트 스윕 — 몸집별 pitch).
- **배경음**: 90년대 홍콩 영화풍의 잔잔한 곡. 중국 5음계(宮商角徵羽 = D E F# A B) 위에
  D–Bm–G–A 진행, 고쟁(古箏)풍 뜯는 소리 + 얼후(二胡)풍 선율 + 낮은 패드 + 베이스,
  68 BPM, 합성 잔향. 마디마다 프레이즈를 골라 쓰기 때문에 돌 때마다 조금씩 다르다.
- 자동 재생하지 않는다. 시작 버튼(사용자 동작) 뒤에 켜지고, 툴바의 `🎵`·`🔊`로 끌 수 있다.

## 3D

- three.js는 `vendor/`에 넣어 뒀다 (CDN 없이 링크 하나로, 인터넷 없이도 돌게).
- 3D를 못 쓰는 환경(WebGL 없음 등)이면 자동으로 STEP B의 2D 화면으로 되돌아간다.
- 테이블 위(산·주사위·버림패·공개 묶음·상대 손패·산가지)는 3D, 내 손패는 DOM이다.
  작은 화면에서 손패는 크고 정확하게 눌러야 하기 때문.
- 그림자(PCF soft shadow)와 **대나무색 등판**으로 초록 바닥에서 패가 뜨지 않고
  입체감 있게 읽힌다. 실물처럼 앞면 상아 + 등판 대나무.
