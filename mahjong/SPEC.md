# 대만마작 학습용 게임 — 스펙 (절대 기준)

> 이 문서가 항상 우선한다. 일반 대만마작 교재(144장·꽃 8장)와 숫자가 다르며,
> 인터넷 규칙과 충돌하면 여기 적힌 것이 이긴다.

## 1. 내 세트 스펙

### 1-1. 전체 구성 — 총 140장
| 종류 | 내용 | 장수 |
|---|---|---|
| 통(筒) | 동그라미 1~9, 각 4장 | 36 |
| 삭(索) | 막대기 1~9, 각 4장 | 36 |
| 만(萬) | 한자 1~9, 각 4장 | 36 |
| 바람 | 東南西北, 각 4장 | 16 |
| 삼원 | 中發白, 각 4장 | 12 |
| 꽃 | 春夏秋冬(사계절만), 각 1장 | 4 |
| **합계** | | **140** |

### 1-2. 일반 교재와 다른 점
- **꽃은 사계절 4장뿐.** 매란국죽 없음 → 八仙過海·花槓 등 꽃 8장 기준 규칙 전부 없음.
- **백(白)은 무늬 없는 백지패.** (실물엔 무지패 8장이 있으나 4장만 백으로 쓰고 4장은 예비.)
- **만자 5는 '五'가 아니라 '伍'.**
- **삭 특징:** 1삭은 새(공작) 그림, 8삭은 지그재그(W) 두 줄, 5·7·9삭엔 빨간 막대 섞임.
- 자리별 정화: **동=春, 남=夏, 서=秋, 북=冬**.

### 1-3. 산가지 & 주사위
- 산가지 52개, 주사위 2개.
- 빨간 점 1개 = **10점** (22개) / 검은 점 8개 = **50점** (21개) / 빨간 점 5개 = **100점** (9개).

패 얼굴 디자인 레퍼런스: 초록 가죽 케이스, 1삭 새, 8삭 W, 5만=伍, 백=백지.

## 2. 게임 규칙

### 2-1. 인원별 세팅
| 인원 | 빼는 패 | 쓰는 장수 |
|---|---|---|
| 4인 | 없음 | 140장 |
| 3인 | 만자 36장 | 104장 |
| 2인 | 만자 36장 + 꽃 4장 | 100장 |

- 손패 16장, 딜러만 17장. 완성형 = 3장 묶음 5개 + 짝 1개 = 17장.
- 묶음: **계단**(같은 무늬 연속 3장, 글자패 불가, 9→1 불가) / **세쌍둥이**(똑같은 3장).
- 짝은 딱 하나. **이길 조건(최소 판수) 없음 — 완성만 하면 승리.**

### 2-2. 부르기
- **펑(碰):** 같은 패 2장 + 누가 그 패 버림. 누구한테서나.
- **치(吃):** 계단 조각 2장 + 모자란 1장. **내 바로 왼쪽 사람이 버린 것만.**
- **깡(槓):** 같은 패 4장, 공개 후 담 뒤쪽에서 보충. 기본 OFF(옵션).
- **완성(胡):** 짝만 모자랄 때 그 패가 버려지면 남의 패로도 이길 수 있다.
- 공개한 묶음은 잠금. 버린 패는 회수 불가 — 방금 버려진 한 장만 즉시 부를 수 있다.
- 우선순위: **완성 > 펑·깡 > 치.** 부르기는 의무가 아니라 선택.

### 2-3. 진행 방향
반시계(동→남→서→북). 내 다음은 오른쪽, 내 왼쪽이 나에게 흘려준다.
한 턴: **뽑고 → 버리고.** 펑·치로 가져왔으면 뽑기 생략.

## 3. 산가지 · 점수 · 환전

### 3-1. 시작 자금
| 인원 | 10점 | 50점 | 100점 | 1인 시작액 |
|---|---|---|---|---|
| 4인 | 5 | 5 | 2 | 500 |
| 3인 | 5 | 7 | 3 | 700 |
| 2인 | 10 | 10 | 4 | 1,000 |
남는 산가지는 가운데 거스름돈 더미.

### 3-2. 점수 (초보용 기본값)
- **받는 점수 = (보너스 개수 + 1) × 10점** (기본점 10 + 보너스당 10)
- 기본 보너스 4개: 안 부르고 이김 / 직접 뽑아 이김 / 내 꽃 / 中發白 세쌍둥이(하나당)
- **특칙:** "안 부르고 + 직접 뽑아"는 2가 아니라 **3**.
- 남이 버린 패로 완성 → 그 사람 혼자 전액. 직접 뽑아 완성 → 나머지 전원이 각각 전액.
- **2인 특칙:** 직접 뽑아 이기면 상대가 2배.

### 3-3. 확장 보너스 (토글)
| 이름 | 조건 | 보너스 |
|---|---|---|
| 混一色 | 숫자패 한 무늬 + 글자패 | 4 |
| 碰碰胡 | 묶음 5개 전부 세쌍둥이 | 4 |
| 小三元 | 中發白 중 둘 세쌍둥이 + 하나 짝 | 4 |
| 門風 | 내 자리 방향 글자 세쌍둥이 | 1 |
| 清一色 | 글자패 없이 한 무늬로만 | 8 |
| 大三元 | 中發白 모두 세쌍둥이 | 8 |
| 大四喜 | 東南西北 모두 세쌍둥이 | 16 |
| 字一色 | 전부 글자패 | 16 |
겹칠 때 대부분 합산, **포함 관계면 큰 쪽만**.
기본점/보너스점 조정 가능(10/10, 30/10, 10/20).

### 3-4. 환전
한 게임 = 한 바퀴(4인 최소 4판 / 3인 3판×n / 2인 2판×n).
종료 시 손익 = 현재 총점 − 시작액. 환율(예: 10점=100원)로 금액 표시(계산·표시만).

## 4. 진행 순서 (모션 단위)
1. 패 섞기 → 2. 산(벽) 2단 쌓기 → 3. 주사위로 입구 정하기 → 4. 배패(벽돌 2개씩 4바퀴,
딜러 1장 더) → 5. 꽃패 처리(뒤쪽에서 보충) → 6. 본 게임 → 7. 부르기 처리 →
8. 완성 선언 → 9. 점수 계산 & 산가지 이동 → 10. 딜러 승계 → 11. 환전 화면.

## 5. 학습 모드 / 실전 모드
**학습 모드**: 가이드 자막, 손패 코치(몇 묶음·무엇을 버릴지), 텐파이 대기패 표시,
패별 연상 고리, 한 수 물리기.
**실전 모드**: 힌트 없이 빠르게, 누가 무엇을 버렸는지만.
공통: 첫 시작 때 기본 룰 카드 6장(넘기기·밀기·건너뛰기, 나중에 `?`에서 다시 보기),
일시정지, 연상 고리 모음 보기, 자동 정렬.
(자동 정렬 끄기는 STEP F 설정에서.)

### 연상 고리(mnemonic)
- 세 무늬 순서: "동전(통)→꿴 꾸러미(삭)→만 냥 지폐(만)"
- 1삭이 새: "돈은 한 푼 남으면 새처럼 날아간다"
- 8삭: "지그재그 두 줄 = 4개+4개"
- 中發白: "과녁에 명중 → 돈을 발사 → 백지수표"
- 백: "그게 백(白)이다 — 원래 백지"
- 동남서북: "동남아 갔다가 서북쪽으로 돌아온다"
- 꽃·자리: "봄에는 동쪽에서 해가 뜬다"
- 차례 방향: "마작 테이블 시계는 거꾸로 간다"
- 계단 vs 세쌍둥이: "계단은 같은 재질만, 세쌍둥이는 누구나"
- 짝 필요성: "머리 없는 참새는 못 난다"
- 한 턴: "들이쉬고(뽑고) → 내쉬고(버리고)"
- 치는 왼쪽만: "계단은 위에서 굴러 내려온다"
- 부르기 우선순위: "이기는 게 먹는 것보다 세고, 세쌍둥이가 계단보다 세다"
- 뭘 버릴까: "끝(1·9)은 외롭다, 가운데(4·5·6)는 인기 많다"
- 남 패로 이기면: "총 쏜 사람이 혼자 물어낸다"
- 보너스 원리: "쉬운 길을 포기할수록 점수가 오른다"
- 부르기: "급하면 부르고, 크게 먹으려면 참는다"
- 버림패: "강물에 흘려보낸 것 — 방금 떨어진 한 장만 낚아챈다"
- 공개한 묶음: "시멘트로 굳은 벽돌 — 빼지도 바꾸지도 못한다"

## 6. 상대 캐릭터 — 우리 집 고양이
포도(제일 작음·높은 야옹) / 감자(중간) / 막내(제일 크고 뚱뚱·낮은 야옹).
2인 = 포도, 3인 = 감자·포도, 4인 = 셋 다. 실제 사진 아바타 + 상황별 말풍선
이모지(인사·펑·완성·잃음·뺏김·유국) + 합성 야옹.
모든 동작은 손이 한다: 내 쪽 사람 손, 상대 쪽 고양이 앞발이 패를 집고 놓는다.

## 7. 봇 AI
난이도 3단계: 초보(랜덤+기본 원칙) / 보통(효율 계산) / 고수(텐파이·안전패).
기본 전략: 외톨이 글자패·끝수 먼저 버림, 무늬 좁히기, 텐파이 지향.

## 8. 기술 스택
HTML + JS(모듈) + Three.js. 빌드 없이 로컬에서 열리게. 모바일 세로 우선.
규칙 엔진(순수 JS, 테스트 가능)과 3D 렌더러 분리. localStorage 대신 메모리 상태.

## 9. 개발 순서
- **STEP A** 규칙 엔진 + 유닛 테스트 ← *완료*
- **STEP B** 2D 플레이 가능 버전 (2인부터) ← *완료*
- **STEP C** 학습 모드 (자막·코치·텐파이·연상 고리) ← *완료 — 실전 모드와 두 갈래*
- **STEP D** 3D 전환 (Three.js) + 소리 ← *완료*
- **STEP E** 3인·4인 확장 + 봇 난이도 + 확장 보너스 토글
- **STEP F** 환전 화면, 설정, 마무리
